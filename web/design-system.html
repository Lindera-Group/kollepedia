Introduction

The NG identity is warm-paper editorial: paper surfaces, ink text, one bläckblå interaction accent, a semantic diff palette for the Time Machine, and a pure-CSS paper grain. Content is serif (Crimson Pro — kontraktet v1.1), UI chrome is sans (Familjen Grotesk), metadata is mono (Fragment Mono). Three themes: light (paper), dark (night desk), contrast (WCAG-AAA-leaning — no shadows, no grain, pure hues). Cycle the theme above: every specimen on this page is drawn from the live src/app.css, so the manual can never diverge from the app.

Rules and checklists live in .claude/skills/ui-guardrails/.

Design Tokens

The counting rule: 3 surfaces / 3 inks / 2 lines — no fourth level, ever. Every token is defined in all three themes. Swatches below are live var() references; hex values live in app.css only.

--bg --bg-raised --bg-sunken --ink --ink-2 --ink-3 --line --line-strong

Surfaces: bg = page ground · raised = cards, popovers, inputs · sunken = recessed, quiet-hover. Ink: --ink-3 is the contrast floor.

--accent --accent-soft --on-accent --focus

The accent is the interaction color — links, primary buttons, selection, active states. It is never decoration (that was v1's accent role; it is gone).

--del-wash --del-strong --ins-wash --ins-strong --blame-wash --endorsed --sepia

The diff palette — the Time Machine's semantics. Only for version/diff/endorsement meaning, never decoration. --endorsed gold is reserved for endorsement; --del-strong also carries destructive UI (that IS its semantic).

  • Radius — 5 tokens, zero literals: --radius-sm 4px (tags, diff highlights) · --radius-md 8px (buttons, inputs) · --radius-lg 14px (cards, popovers) · --radius-pill 999px (pills, chips, count badges) · --radius-round 50% (icon buttons, avatars, dots). No --radius-xl, no modals, never v1's 12px — and never a raw 999px/50% in a component (the guard fails it).
  • Spacing: the v1 4px grid unchanged — --space-1 … --space-16.
  • Elevation: two shadows only (--shadow-sm, --shadow-md); contrast theme has none.
  • Atmosphere: the paper grain (body::before, --grain-opacity) is visible on this page right now — pure CSS, pointer-transparent, off in contrast.

Content serif · chrome sans · metadata mono. Never mix roles. Fonts are self-hosted via @fontsource — never a CDN link. Headings: weight 560, letter-spacing −0.01em. Heading sizes are GLOBAL (app.css): h1 = 2xl, h2 = xl, h3 = lg (≤640px: xl/lg) — pages declare none of their own. Sanctioned overrides: home hero (display), card-title h2 (lg), auth-card/guard h1 (xl), label-h2 (xs uppercase). --text-brand (2.5rem) belongs to the header wordmark alone — h1 sits below it (2.2rem) so page titles never compete with the logotype (2026-07-12).

Buttons — 4 archetypes + icon

Every button is one of these; no new button styles. Local needs compose a modifier on top of .btn.

.btn-primary accent fill · .btn outline, inverts on hover · .btn-quiet borderless, sunken hover · .btn-danger del-strong outline, fills on hover. Press = translateY(1px). Icon-only buttons: .icon-btn + aria-label, SVG aria-hidden.

Forms

The real primitives: .field-label (uppercase — --text-xs, 600, 0.04em tracking, --ink-3) and .input (--radius-md, --line border, --bg-raised, sans, focus = accent border). Before 2026-07-12 this recipe was copy-pasted 41 times; now the guard bans bare input/textarea/select styling. Layout (width, min-height) stays local. Search-and-pick = the ConceptCombobox ARIA pattern. Exception: the home hero search is serif + --radius-lg (it is content, not chrome).

Feedback — the inline idiom

NG deliberately has no toast system. Errors are persistent inline role="alert"; transient status is role="status". Destructive flows never use confirm() — two sanctioned patterns:

Anna Andersson har tagits bort ur organisationen.

Inline undo (reversible actions): act immediately, offer Ångra for ~6s. Precedent: orgs member removal.

Stänga av K2 Nationellt kunskapscentrum?

Inline two-step confirm (hard-to-reverse): the trigger swaps in place for a role="alert" question. Precedent: org suspension.

Kunde inte spara: definitionen är låst av en pågående ändringsförfrågan.

Errors are persistent and specific — never auto-dismissed, never "Något gick fel".

The versions-DAG sets NG's bar for custom widgets: a hand-built git-graph SVG, a playhead with a full keyboard model (role="slider", ←/→ step, Home/End, Space, ↑/↓ between lanes), and diff semantics always through the diff palette.

Word-diff: --del-wash/--del-strong strike-through vs --ins-wash/--ins-strong. Blame ink ages text via color-mix(in oklab, currentColor …, var(--sepia)) + weight + opacity — three channels, so color alone never carries meaning. Endorsed versions get the gold halo:

Motion & misc

  • Never transition: all. Chrome 0.15s, content 0.2–0.25s, never > 0.3s. Easing via --ease-out / --ease-in-out.
  • The slide-in menu: panel always in the DOM, inert when closed; Escape closes; focus goes to the first link on open and back to the hamburger on close.
  • Sticky header: backdrop-filter: blur(10px) + color-mix background (this page's header demonstrates it).
  • Infinite lists: InfiniteSentinel + scroll restore — not pagination.
  • Icons (2026-07-10): every icon comes from $lib/icons (grid 20×20, stroke 1.5, round, currentColor — themes for free). Inactive = outline · active = filled + semantic color (watching green, endorsed gold, unread green). Flat, no gradients. ONE glyph per concept everywhere: rectangular speech bubble = discussion, dial clock = history, bell = watching/activity. Check the library BEFORE drawing a new icon; new icons go INTO the library. Counts always render as .count-badge (mono on soft plate; green .unread variant).
  • Global a11y utilities: .sr-only (never local copies), .skip-link, global :focus-visible = 2px --focus.
  • Page shell: root is .container (1100px) — only variant: .container.narrow 640px (konto/auth). .container.wide är avvecklad (kontraktets princip 8) — a component that needs the whole viewport uses .full-bleed (width 100vw, centered breakout; the inner element owns its horizontal scroll — precedent: jämförelsevyns kolumnrullare). Rhythm comes from the layout's main (space-8 top / space-16 bottom); pages add no own page-level padding. .breadcrumb is global.
  • Breakpoints: 900px collapse, 640px single column, 375px baseline.

The mechanical guard

Nothing on this page is enforced by memory. scripts/design-guard.mjs fails the build on: hardcoded colors/font-sizes/radii/spacing in components, undefined var(--…) tokens, transition: all, local .badge/.sr-only/ .filter-btn definitions, local restyling of any global primitive, bare input/textarea/select recipes, tokens missing a theme — and this manual drifting: every class defined in app.css must appear on this page.

  • Runs: every npm test (vitest: design.guard.test.ts) → CI, and the repo pre-commit hook (.githooks/pre-commit).
  • Manually: node scripts/design-guard.mjs from web/.
  • Escape hatch (rare, reviewed): append /* design-guard-exempt: <reason> */ on the line. Precedents: mask alpha stops, viz micro-labels below the type scale.
  • New primitive? Define it in app.css (all three themes), add its specimen here, then use it — the guard forces all three steps.
